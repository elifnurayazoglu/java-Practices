# HexDigitConverter

A simple Java application that converts single-digit hexadecimal numbers to decimal.

## Features
- Converts single-digit hex values (0-9, A-F) to decimal
- Shows an error message for invalid input
  
## Technologies Used
- Java
- NetBeans IDE
- Maven

## How It Works
The program takes a single hex character as input and prints its decimal equivalent.

| Hex | Decimal |
|-----|---------|
| 7   | 7       |
| A   | 10      |
| F   | 15      |

## Getting Started
1. Clone the repository:
   `git clone https://github.com/elifnurayazoglu/java-Practices.git`
2. Open the `HexDigitConverter` folder in NetBeans via **File → Open Project**
3. Run the project with **Run** (F6)

## Example
Input: `B`
Output: `11`
